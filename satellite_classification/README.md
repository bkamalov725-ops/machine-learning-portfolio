# Классификация спутниковых изображений

Воспроизводимое решение учебного соревнования: классификация спутниковых снимков на **20 классов** с помощью предобученных CNN. Здесь сохранён финальный вариант V7 без изменений архитектур и алгоритма обучения.

**Публичный Accuracy — 0.96660**, по результату отправки, сообщённому автором. Этот результат не проверен независимо; приватный скор неизвестен. Репозиторий — архив завершённого соревнования, а не обещание аналогичного результата на новых данных.

## Что вошло в финальное решение

Предсказания двух моделей объединяются на уровне вероятностей:

```text
P(class | image) = 0.60 × P_ResNet152 + 0.40 × P_Inception_v3
```

Для каждой модели используется D4 test-time augmentation: четыре поворота на 90° и их отражённые варианты, всего **8 видов**. Сначала усредняются вероятности видов каждой модели, затем применяется смесь 60/40 и выбирается класс с максимальной вероятностью.

Предобученные веса — только официальные ImageNet-веса из `torchvision`. Transformers, внешние датасеты и внешние обученные модели не используются.

## Обучение и оценка

1. MLP, собственная CNN и предобученные модели обучаются только на `train`. Размеченный `val` используется для сравнения моделей и заранее заданных рецептов ансамбля.
2. Выбранный рецепт фиксируется. Финальные ResNet152 и Inception v3 обучаются заново на `train + val`; примеры `val` включены с повторением ×2.
3. После завершения финального обучения сохранённые FP32 EMA-веса используются для предсказания `test` и создания CSV.

`test` не используется для обучения моделей или подбора предобработки, признаков и рецепта. Нет псевдометок теста, подгонки распределения классов или ручного изменения предсказаний. Фиксированные преобразования тестовых изображений выполняются только при инференсе.

### Результаты сравнения на validation

| Модель / рецепт | Верно из 699 | Accuracy |
| --- | ---: | ---: |
| MLP, 8 эпох | 176 | 0.251788 |
| Собственная CNN, 8 эпох | 418 | 0.597997 |
| ResNet101 + D4 | 676 | 0.967096 |
| Inception v3 + D4 | 678 | 0.969957 |
| ResNet152 + D4 | 680 | 0.972818 |
| 60% ResNet152 + 40% Inception v3, D4 | **682** | **0.975680** |

Это результаты этапа выбора с обучением только на `train`. Validation уже использовалась в предыдущих экспериментах, поэтому **682/699 — не независимая оценка финального решения и не тестовый скор**. После переобучения на `train + val` отдельный validation Accuracy не заявляется.

### Настройки финальных моделей

| Параметр | ResNet152 | Inception v3 |
| --- | --- | --- |
| Размер входа | 224 × 224 | 299 × 299 |
| Batch size | 16 | 24 |
| Seed | 2026 | 2029 |
| Завершённые эпохи | 14 | 14 |
| Вес в ансамбле | 0.60 | 0.40 |

Общие настройки:

- AdamW: learning rate `2e-4` для обучаемой предобученной части и `2e-3` для классификатора; weight decay `0.05`.
- Собственный классификатор, dropout `0.3`, label smoothing `0.1`.
- Warmup и cosine schedule, AMP, ограничение нормы градиента; EMA с decay `0.999` и разогревом.
- У ResNet заморожены ранние блоки и их статистики BatchNorm.

Аугментации при обучении: случайный crop, горизонтальные и вертикальные отражения, повороты на 90°, изменения цвета, blur, JPEG-сжатие с качеством 8–45, уменьшение разрешения, grayscale и Gaussian noise. Также применяются MixUp/CutMix. Реализация основана на преобразованиях `torchvision`.

### Время на двух Tesla T4

- Финальное обучение двух моделей заново с ImageNet-весов: **22.9894 минуты** — около 22 минут 59 секунд.
- Полный запуск с предварительными сравнениями, инференсом и сохранением: **57.115 минуты**.
- Условие курса: не более 45 минут именно на **обучение финального решения**, а не на весь `Run All`. Ноутбук отдельно сохраняет фактически измеренное время.

Время относится к зарегистрированному запуску и зависит от оборудования и окружения. Ограничитель времени не заменяет фактический замер.

## Запуск на Kaggle

1. Импортировать [`notebooks/solution_kaggle.ipynb`](notebooks/solution_kaggle.ipynb).
2. Подключить официальный датасет соревнования в Input. Исходные данные не распространяются в этом репозитории.
3. Выбрать GPU **Tesla T4 ×2** и включить Internet для загрузки разрешённых ImageNet-весов.
4. Выполнить `Run All`. Старые пользовательские веса и архивы для первого запуска не нужны.
5. Скачать CSV, отчёт, ноутбук и recovery-архив из `/kaggle/working/geo_v7_45`.

Основные выходные файлы:

- `submission_geo_v7_45.csv` — предсказания для отправки.
- `REPORT_V7_45_TO_SEND.txt` — агрегированный отчёт.
- `final_training_time.json` и `final_wallclock_notebook.json` — измерения времени финального обучения.
- `geo_v7_45_recovery.tar.gz` — приватный архив кода, конфигураций, результатов и весов для восстановления.

**Сохраните FP32-веса и recovery-архив отдельно, в приватном хранилище.** Одних seed недостаточно для гарантии побитового воспроизведения CSV: результат также зависит от версий библиотек, оборудования и сохранённых весов.


Проверенное окружение запуска: Python **3.13.15**, PyTorch **2.11.0+cu128**, torchvision **0.26.0+cu128**, CUDA **12.8**, две Tesla T4. GPU-версии PyTorch требуют совместимых драйверов и подходящего источника пакетов; в Kaggle следует использовать готовое окружение.

### Локальная проверка и сборка

Из корня проекта, в PowerShell:

```powershell
python -m pip install -r requirements.txt
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
python src/build_notebook.py
```

Тесты используют синтетические данные: они проверяют поведение кода, но не подтверждают Accuracy на соревновании или время GPU-обучения. Сборка восстанавливает самодостаточный ноутбук из исходников.
